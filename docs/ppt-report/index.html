🎯

问题背景

  • 本地 Mac 无法安装 COMSOL/Lumerical
  • COMSOL 波长谱计算速度慢
  • 需要利用远程 Windows 机器的算力

  • sim-cli 统一仿真控制框架
  • 插件架构支持多求解器
  • 技能系统指导 AI agent

插件

插件架构详解

sim-plugin-comsol

class ComsolDriver: name = "comsol" supports_session = True def connect(self): # 使用 mph 库连接 COMSOL import mph self.client = mph.Client() def run(self, code, label): # 执行 Java/Python 代码 self.model.evaluate(code)
  • 使用 mph Python 库
  • 通过 JPype 调用 Java API
  • 端口：7600

sim-plugin-lumerical

class LumericalFDTDDriver: name = "lumerical-fdtd" supports_session = True def connect(self): # 通过 HTTP 连接远程服务器 self.client = LumericalClient( host, port ) def run(self, code, label): # 发送 HTTP 请求执行 self.client.post("/exec", json={"code": code})
  • 使用 lumapi Python 库
  • 通过 HTTP 控制远程服务器
  • 端口：7601

sim-plugin-cmd ⭐新增

class CmdDriver: name = "cmd" supports_session = True def launch(self, shell="cmd"): # 创建会话 state = SessionState( shell=shell, ... ) def run(self, code, label): # 执行 shell 命令 subprocess.run( ["bash", "-c", code])
  • 使用 subprocess 标准库
  • 直接执行本地命令
  • 端口：7602
# 插件注册 (pyproject.toml) [project.entry-points."sim.drivers"] comsol = "sim_plugin_comsol:ComsolDriver" lumerical-fdtd = "sim_plugin_lumerical:LumericalFDTDDriver" cmd = "sim_plugin_cmd:CmdDriver" # ⭐新增

安全

CMD Server 安全功能 ⭐新增

保护远程命令执行的安全性

🔐

用户名密码认证

连接时需要提供凭据，防止未授权访问

✅

远程确认机制

首次连接需确认一次，后续命令无需确认

⏰

超时退出机制

无活动超时后自动关闭服务器

启动命令示例

# 完整安全配置 python cmd_server.py ` --port 7602 ` --host 0.0.0.0 ` --username admin ` --password mypassword ` --timeout 600 ` --require-confirm # 参数说明 --port # 监听端口 --host # 绑定地址 --username # 认证用户名 --password # 认证密码 --timeout # 超时秒数 (0=禁用) --require-confirm # 启用确认机制
# 连接流程 # 1. 认证连接 curl -X POST http://100.65.228.190:7602/connect \ -d '{"solver": "cmd", "username": "admin", "password": "mypassword"}' # 2. 确认会话（只需一次） curl -X POST http://100.65.228.190:7602/confirm \ -d '{"session_id": "cmd-xxx"}' # 3. 执行命令 curl -X POST http://100.65.228.190:7602/exec \ -d '{"code": "dir", "session_id": "cmd-xxx"}'

COMSOL 会话管理

# sim-server 内置管理 class SessionState: session_id: str solver: str driver: ComsolDriver connected_at: float # /connect 时创建 driver = ComsolDriver() driver.connect() # /exec 时复用 driver.exec(code) # /disconnect 时清理 driver.disconnect()

CMD 会话管理 ⭐新增

# 自定义实现（带安全功能） class SessionState: session_id: str shell: str # cmd/bash/powershell confirmed: bool # 是否已确认 last_activity: float # 超时检测 # /connect 时创建 state = SessionState(shell=shell) # /confirm 时确认 state.confirmed = True # /exec 时检查确认状态 if not state.confirmed: return {"error": "需要确认"} # /disconnect 时清理 sessions.pop(session_id)
